> 本文档记录**主 Agent 对交付物的独立验证**：验证了什么、怎么验证的、结果如何、以及**哪些没有验证**。

## 0. 为什么需要这份记录

本项目有三层验证，各自回答不同问题：

| 层 | 回答的问题 | 覆盖不了什么 |
|---|---|---|
| 程序员自测（305 条 pytest） | 「我写的东西按我的理解工作吗」 | 我对 API 的理解本身就是错的（例：文件名解析 14 个错 11 个） |
| PM 用户视角验收（132 条） | 「真实服主用起来顺不顺、会不会被误导」 | 只有 PM 想到的场景 |
| **主 Agent 独立验收（本文档）** | 「它在**真实数据**与**边界组合**下真的对吗」 | 需要真机环境的东西（Linux、旧控制台） |

三层里，**只有第二层能发现「误报为绿」这类问题，只有第三层能发现「打包后配置丢失」这类问题**。

## 2. 已验证通过的项目

### 2.1 核心判定
- 真实 30 模组 @26.3/fabric：🟢21 / 🟡7 / 🔴2，**与独立基准逐条一致**；
- 六分支判定 + 多加载器同版本号陷阱 + 作者重发旧版本陷阱，全部正确；
- 200 模组规模下**连跑 3 次结论完全一致**。

### 2.2 数据完整性
- 无元数据 jar **进清单**（3 个 jar → 3 条），不再静默丢弃；
- 两条识别路径写入**同一种**平台标识（都是 slug），改文件名重扫不会产生重复；
- 带 BOM 的用户清单文件（记事本/PowerShell 生成）导入后第一条干净；
- 清单合并幂等：同一文件夹扫两次仍是 30 条。

### 2.3 网络与健壮性
- 指纹反查批量 POST 不会因缓存键串味而张冠李戴；
- 限速器在**注入异常时钟**时会抛领域异常而非永久自旋（修复后 CPU 0.16 秒返回）；
- 数据源整体不可用 → **退出码 4**（且部分失败不会被误升级成 4）；
- 限流/超时一律标 ⚪，**从不变红**。

### 2.4 输出与成品感
- 输出净化：9 条命令的 stdout/stderr 零命中内部标识与英文异常原文；
- 分隔线与表格宽度一致（104 == 104）；
- 重定向时保留发布日期列、不弹交互、不画进度行；
- 表格对齐按**显示宽度**（中文算 2 列）而非字符数；
- «warn.xxx» 之类的缺键泄漏已消除。

### 2.5 打包与平台
- Nuitka **standalone 与 onefile 两种模式真机构建并运行**；
- 两种模式的 `config path` 都落在 **exe 同级目录**（便携模式生效，未落进 %TEMP%）；
- 打包产物端到端扫描真实 30 模组正常；
- 跨平台静态审计：无 Windows 专属依赖、无 POSIX 裸导入、路径全用 pathlib、编码全显式。

### 2.6 中断
- Ctrl+C：返回码 **130**、无 traceback、输出「结果不完整」的中断摘要。

## 4. 验证过程中发现并修复的问题（按发现顺序）

| # | 问题 | 若漏掉的后果 |
|---|---|---|
| 1 | 文件名解析在实际模组上 14 个错 11 个 | 扫描建清单的核心卖点不成立 |
| 2 | 全量拉取版本列表（JEI 单模组 6.8 MB） | 200 模组拉 326 MB 并撞限流 |
| 3 | 按「全局最新」判定 | JourneyMap 被误判为需降级（假黄） |
| 4 | `_YEAR_BASED_MAJOR` 未定义 | 无版本清单时整条路径崩溃 |
| 5 | 通道词无边界匹配 | servercore/architectury 等真实模组识别失败 |
| 6 | argparse 退出码 2 与「有未判定项」撞码 | 脚本无法区分参数错误与检查结果 |
| 7 | classify 分支③信任调用方传参 | **误报为绿 → 服主升级后崩服** |
| 8 | Provider 默认实现全量拉取 | 性能设计整体失效 |
| 9 | POST 缓存键只含 URL | 批量指纹反查张冠李戴 |
| 10 | Nuitka 下 `sys.frozen` 不存在 / onefile 的 `sys.executable` 指向临时目录 | **便携配置静默失效；onefile 下用户清单随退出消失** |
| 11 | 跨路径 key 不收敛 | 先导文件名再扫 jar 得到 46 条而非 30 条 |
| 12 | 读用户文本文件未处理 BOM | 记事本编辑过的清单第一条永远匹配不上 |
| 13 | 限速器在异常时钟下永久自旋 | 测试套件随机挂死（实际卡死过 10 分钟） |
| 14 | 中断后打印**错误**的空清单结论 | 诱导用户重扫，可能覆盖人工编辑的清单 |

## 5. 复现方式

```powershell
$py = ".toolchain\Python311\python.exe"
& $py docs\research\21_final_verification.py      # 30 道关卡总控
```
