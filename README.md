# modcheck —— Minecraft 模组兼容性检查

> 在**升级服务端游戏版本之前**，一条命令查清：你服务器上的模组，是否都已经支持目标版本与加载器。

升级 Minecraft 版本最麻烦的不是升级本身，而是**升级完才发现某个模组不支持** —— 服务端起不来，或者起来了但某个功能悄悄失效。
modcheck 把这件事提前：它读你的 mods 文件夹，逐个去 Modrinth 查证，然后告诉你哪些能用、哪些必须处理。

---

## 它给出的结论

| 状态 | 含义 | 你该做什么 |
|---|---|---|
| 🟢 就绪 | 目标版本上有可用版本 | 不用管 |
| 🟡 需注意 | 最新正式版不支持，但**有一个更早的稳定版**可用 | 用那个旧稳定版，别下最新版 |
| 🟠 仅存测试版 | 只有 alpha/beta 支持目标版本 | 自行评估风险，建议先备份存档 |
| 🔴 阻塞 | 目标版本上没有任何可用版本 | 必须先解决，否则无法升级 |
| ⚪ 未判定 | 没查到（**不算失败**） | 可稍后重跑；必要时手动指定平台项目 |
| ⚫ 已忽略 | 你主动标记为不参与检查 | 不参与判定 |

**它不会猜。** 查不到就如实报「未判定」，绝不为了看起来完整而随便选一个版本 ——
一个错误的「就绪」比一个诚实的「未判定」危险得多。

## 两种版本，按需选择

同一份判定逻辑，两个前端：

| | 命令行版 | 图形界面版 |
|---|---|---|
| 适合 | 熟悉命令行、想写脚本、在意体积 | 想点几下就用、看表格更直观 |
| 下载体积 | 约 24 MB（免安装压缩包） | 约 28 MB（含 Qt） |
| 依赖 | **零第三方依赖**，只用标准库 | 需要 PyQt6（已打包进产物） |

**两者读同一份配置与清单**，随时可以换着用，数据互通。

## 快速上手

### 图形界面版

1. 把 `modcheck-*-gui.zip` 解压到**任意一个文件夹**（不要只把 exe 单独拖出来，它需要旁边的文件）。
2. 双击 `启动GUI.cmd`。
3. 菜单栏 **清单 → 扫描 mods 文件夹…**，添加你服务端的 mods 文件夹，点「开始扫描」。
   *扫描完成后还会联网识别一会儿，界面会提示「正在联网识别」—— 这一步要逐个查询，可能需要几分钟。*
4. 给清单起个名字（例如「生存服」）并保存。
5. 回到主窗口，选好清单、目标版本、加载器，点 **开始检查**。
6. 看结论横幅与分页签；点某一行可在下方看到具体建议。

需要下载可用版本时，点 **下载建议版本…** —— 它只下 🟢🟡 两类里建议你使用的那个版本，
同名文件会先问你，**默认不覆盖**。

### 命令行版

1. 解压到任意文件夹。
2. 双击 `启动CLI.cmd`进入中文菜单。
3. 选 `[2]` 扫描 mods 文件夹建立清单。
4. 选 `[1]` 检查模组兼容性。

也可以直接一条命令跑完（适合写脚本）：

```bat
modcheck.exe check --profile 服务器A --mc 26.3 --loader fabric --no-color
```

> **所有配置与清单都存在程序同级的 `config\` 目录里**，整个文件夹可以随身拷走（绿色便携）。
> 第二次检查会命中缓存，几秒就能出结果。

**更详细的图文教程见 [docs/TUTORIAL.md](docs/TUTORIAL.md)**，程序内的「帮助 → 使用教程」也有同一份内容。

## 它不做的事

- **不修改你的 mods 文件夹**。默认只读；下载必须由你主动触发，且只写入你指定的文件夹。
- **不自动替换或安装模组**。下载下来的文件放在哪、要不要用，由你决定。
- **不重新分发模组文件**。下载的是 Modrinth 官方 CDN 直链。
- 不做快照版本检查、不做依赖递归解析。

## 给开发者

Python 3.11+，**运行时零第三方依赖**（图形界面除外，见下）。

**分层架构**（单向依赖，有自动化检查守着）：

```
core/     纯判定与数据：无 IO、无 print/input/sys.exit，不依赖任何前端
  ↓
flows/    流程编排：扫描识别、兼容性检查、下载、导入导出
          进度用回调、取消用探针，返回结构化结果，**不打印任何东西**
  ↓
cli/      解析参数 → 调 flow → 渲染成终端文本
gui/      Qt 控件 → 调 flow → 更新界面
```

这条边界是 GUI 能复用流程的前提：判定只有一份实现，所以**命令行与图形界面不可能给出不同结论**。

**自己构建**（需要 Python 3.11+ 与 Nuitka）：

```bash
python build/nuitka_build.py                 # 命令行版（免安装目录）
python build/nuitka_build.py --gui           # 图形界面版（需先安装 PyQt6）
```

**开发与测试**：

```bash
pip install -e ".[dev]"        # 只装测试依赖
pytest                          # 默认跳过需要真实联网的用例
python docs/research/36_layering_check.py     # 分层自检
```

图形界面需要额外安装 PyQt6（`pip install ".[gui]"`）。它是**可选依赖** —— 不装它，命令行版照常工作。

仓库里还留了一批 `docs/research/` 下的验证脚本（逐字快照、分层检查、真实数据复核等），
它们记录了这个项目是怎么被验证的，欢迎在改动后拿它们自查。
